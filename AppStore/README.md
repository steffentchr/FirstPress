# App Store

The App Store material for the two apps, one folder each. Edit the sources there and regenerate; nothing is made by hand.

| Path | What it is |
|---|---|
| [`FirstPress/`](FirstPress) | The iPhone app: screenshots and the sample world in them, the store text, the listing to paste and the review notes. |
| [`FirstPressMenu/`](FirstPressMenu) | First Press Menu, the Mac menu-bar app: screenshots rendered from the real panel, the store text, the listing to paste and the review notes. Its screenshots script also draws the iPhone set's last screenshot. |
| [`privacy-policy.md`](privacy-policy.md) | The privacy policy both listings link to. It covers First Press and First Press Menu, and First Press Menu's Settings links to it at this path. |

Each folder's README lists its files, how to regenerate them, the store fields that aren't in files, and the decisions left before submitting.
