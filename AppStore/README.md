# App Store

The App Store material for the two apps, one folder each. Edit the sources there and regenerate; nothing is made by hand.

| Path | What it is |
|---|---|
| [`Pressing/`](Pressing) | The iPhone app: screenshots and the sample world in them, the store text, the listing to paste and the review notes. |
| [`PressingMenu/`](PressingMenu) | Pressing Menu, the Mac menu-bar app: its store text, the listing to paste and the review notes. |
| [`privacy-policy.md`](privacy-policy.md) | The privacy policy both listings link to. It covers Pressing and Pressing Menu, and Pressing Menu's Settings links to it at this path. |

Each folder's README lists its files, how to regenerate them, the store fields that aren't in files, and the decisions left before submitting.
